# pi-exit

A [pi](https://github.com/earendil-works/pi) extension that adds `/exit` and `:q` as aliases for the built-in `/quit`.

## Install

```bash
pi install git:github.com/danwlsn/pi-exit@v0.1.0  # from github
pi install ./pi-exit                              # from local clone
```

Or try it for one session:

```bash
pi -e ./extensions/exit.ts
```

Then type `/exit` or `:q`.
